# Speed Typing Game

A simple and responsive **Speed Typing Game** built with **HTML, CSS, and Vanilla JavaScript**.

### Features

* Generates random quotes using the DummyJSON API
* Highlights correctly and incorrectly typed characters
* Automatically loads a new quote when completed
* Includes a real-time typing timer
