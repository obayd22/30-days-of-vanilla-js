# Weather App

A clean, responsive weather application that fetches real-time weather data using the WeatherAPI. Built with vanilla HTML, CSS, and JavaScript.

**Live Demo** [here](https://obayd22.github.io/30-days-of-vanilla-js/day-01-weather-app/)

## References: 

- Tutorial: [Video](https://youtu.be/MIYQR-Ybrn4?list=PLjwm_8O3suyOgDS_Z8AWbbq3zpCmR-WE9)
- Images: [drive](https://drive.google.com/file/d/1RgSeYljIBzh-ZHIzEFwWmfGIDEMF1bHr/view)
- [WeatherAPI Current Weather endpoint](https://www.weatherapi.com/docs/)


**Note: I didn't use the same api provided in the video, so, feel free to use anyone available.**


## File Structure

```
├── index.html      # Main HTML structure
├── style.css       # Styling and responsive media queries
├── script.js       # Weather fetching and DOM logic
└── images/         # Icons (search, humidity, wind)
```

## API Reference


```
https://api.weatherapi.com/v1/current.json?key={apiKey}&q={city}
```
