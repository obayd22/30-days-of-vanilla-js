# 30 Days of Vanilla JS 🚀

> One project. Every day. Zero frameworks. Just me, my keyboard, and the browser console.

This repo is my personal challenge to build **30 small projects in 30 days** using nothing but plain HTML, CSS, and JavaScript. No React. No Vue. No build tools. No npm install drama. Just the good old DOM API and some creativity.

---

## Why am I doing this?

Because I realized I was reaching for frameworks before I even understood what the browser could do on its own. Turns out, vanilla JS is pretty powerful — and honestly? It's kinda fun when you're not fighting a bundler.

---

## Rules I set for myself

1. **Vanilla JS only** — No frameworks, no libraries (except APIs for data)
2. **One project per day** — Doesn't have to be huge, just has to work
3. **Mobile-friendly** — Every project needs to look decent on a phone
4. **Deploy immediately** — If it's not live, it doesn't count

---

## Tech used

- HTML5
- CSS3 (flexbox, grid, media queries, the usual)
- JavaScript (Fetch API, DOM manipulation, localStorage when needed)
- [WeatherAPI](https://www.weatherapi.com/) — for the weather app
- GitHub Pages — for hosting (because it's free and easy)
