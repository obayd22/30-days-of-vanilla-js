# Random Password Generator

A simple, responsive web app that generates strong random passwords with one click.

## Features
- Generates a 14-character password with uppercase, lowercase, numbers, and symbols
- One-click copy to clipboard
- Responsive layout (desktop, tablet, mobile)
- Custom favicon
