# QR Code Generator

A simple and responsive **QR Code Generator** built with **HTML, CSS, and Vanilla JavaScript**.

### Features

* Generate QR codes from text or URLs
* Responsive design for mobile and desktop
* Input validation
* Simple animations
* Uses the QR Server API
